# 筋肉カードゲーム 設計メモ

Slay the Spire（スレスパ）型のローグライト・デッキ構築ゲーム。
ライバルとトレーニングで張り合い、相手の心を折ったら勝ち。

---

## 決定事項

### 1. 基本ルール（スレスパと同じ）

1. ターンの最初に山札からカードを **5枚** 引く
2. **スタミナ3** を使ってカードを出す（カードごとにコストあり）
3. ターン終了時、残った手札はすべて捨て札へ
4. 敵が行動する（次の行動は事前に予告表示される）
5. 1に戻る

- メンタル（HP）が0になったら負け
- 敵のメンタルを0にしたら勝ち
- 山札が尽きたら、捨て札をシャッフルして山札に戻す

### 2. 用語

| スレスパ | 筋肉ゲーム | 備考 |
|---|---|---|
| エナジー | **スタミナ** | 毎ターン3 |
| HP | **メンタル** | 自分も敵も |

### 4. 敵（ライバル）

人間のライバル。攻撃は「誘惑」。

- **ザコ**：ジム初心者の大学生、自撮りインフルエンサー、チキンレッグ、プロテインおじさん
- **エリート**：ジムの主（ヌシ）、鬼のパーソナルトレーナー
- **ボス**：地方大会のチャンピオン

#### 敵の行動

| 行動 | 内容 | 例 |
|---|---|---|
| **誘惑** | こちらのメンタルを削る（攻撃） | 「ラーメン行こうぜ」8ダメージ |
| **フォーカス** | 敵も集中してこちらの攻撃を防ぐ | 「黙々とトレーニング」フォーカス6 |
| **パンプアップ** | 敵の攻撃力アップ | 「自撮りで自信UP」パンプ+2 |
| **煽り** | こちらを弱らせる | 「それ効いてる？」動揺を付与 |

#### 誘惑の系統（全部混ぜる）

- 食べ物：「ラーメン行こうぜ」「今日はチートデイでしょ」
- サボり：「今日は休んでいいんじゃない？」「雨だしやめよう」
- マウント・煽り：「その重さでやってるの？」「フォーム崩れてるよ」
- 楽をすすめる：「サプリだけで痩せるよ」

### 6. カードの構造

#### トレーニングカード

```
┌──────────────────┐
│②  ベンチプレス        [バーベル]│ ← コスト / 名前 / 器具
│──────────────────│
│      （ポーズのイラスト）        │
│──────────────────│
│ トレーニング ・ コモン           │ ← 種類 / レア度
│  8ダメージ                       │ ← 効果
│  相手に動揺2                     │
│──────────────────│
│ 胸 ●●  肩 ●  腕 ●              │ ← 部位（メイン / サブ）
│ 🏋 80kg / 100kg                  │ ← 重量（今 / 強化まで）
└──────────────────┘
```

| 項目 | 内容 |
|---|---|
| コスト | 使うのに必要なスタミナ |
| 名前 | 種目名 |
| 種類 | トレーニング / メンタル / メソッド |
| レア度 | コモン / アンコモン / レア（報酬での出やすさが変わる） |
| 器具 | バーベル / ダンベル / ケーブル / マシン / 自重 |
| 効果 | ダメージ・追加効果 |
| 部位 | メイン部位とサブ部位、それぞれの刺激量 |
| 重量 | 今の重量 / 強化までの重量 |

#### メンタルカード・メソッドカード

部位・重量・器具の欄はなし。コスト・名前・種類・レア度・効果のみ。

#### 見た目（レイアウト）

レイアウト案：https://claude.ai/artifact/NcpKQonhHH6FcyzdNqeyzy （「決定案」）

- 配置は **スレスパ型**：コスト（左上の丸）→ 名前・器具 → イラスト → 種類・レア度 → 効果
- 部位は **部位マップ**：胸・背・肩・腕・腹・脚の6マスをいつも同じ順で並べ、メイン部位は濃く、サブ部位は薄く光らせる
- 重量は一番下に、**大きな数字＋10マスのゲージ**で表示
- デザインは **黒い枠**。カードの種類は枠線と種類ラベルの色で見分ける
  - トレーニング：赤 / メンタル：青 / メソッド：紫
- メンタル・メソッドカードは部位マップと重量がないぶん、効果欄を大きくする
- レア度は文字で書かず、種類ラベルの横の **ひし形の色** で表す（コモン：グレー / アンコモン：青 / レア：金）
- 器具は名前の右に **黄色の札**（アイコン＋器具名）で表示

#### 画像の作り方（決定）

- **枠**：Nano Banana で作る（なめらかな高解像度の絵）。背景は緑で出して、後で透明にする
- **イラスト・アイコン**：PixelLab でドット絵を作り、整数倍で拡大してはめ込む
- **文字**：フォントで載せる（名前・コスト：Dela Gothic One、効果文など：M PLUS 1p）
- **コスト**：ダンベルのプレート（円盤）の形にする
- **重量**：ゲージの外枠を広げて、「重量」の文字と「80 / 100kg」の数字も枠の中に収める
- コストのプレートはカードの左上の角に重ね、数字はプレートの中心に置く
- ゲージの目盛りは10個
- 見た目は決定。見本：`assets/nanobanana/cards_all_preview.png`、組み立て用スクリプト：`assets/nanobanana/compose_all.py`

#### 器具ごとの性格

器具の性格は **傾向（カード作りの方針）にとどめる**。器具共通のルールは作らない。
器具を参照する効果は、レリックやメソッドカードで作る（例：「ケーブルマスター」：ケーブルの種目のダメージ+2）。

| 器具 | 性格 | コストの目安 | 例 |
|---|---|---|---|
| バーベル | 高コスト・高ダメージ。BIG3が入る | 2〜3 | ベンチプレス、スクワット、デッドリフト |
| ダンベル | 片手ずつ。2回攻撃が多い | 1〜2 | ダンベルカール（4ダメージ×2回） |
| ケーブル | 低コスト。続けて使うと強くなるカードが多い | 1 | ケーブルクロス、フェイスプル |
| マシン | 安定型。ダメージ＋少しフォーカス | 1〜2 | ラットプルダウン、レッグプレス |
| 自重 | コスト0。弱いけど手軽 | 0 | 腕立て伏せ、懸垂、プランク |

## 検討中

### 部位の成長（独自要素）

#### 決定

- トレーニングカードには **メイン部位** と **サブ部位** がある
  - 例：ラットプルダウン → メイン：背中+2、サブ：腕+1
- 戦闘中は部位に **刺激** が溜まり、**戦闘後のリザルト画面で部位レベルが上がる**
- 部位レベルは **ラン中ずっと残る**
- トレーニングカードには **重量** の欄がある（例：80kg / 100kg）
  - 重量は **メイン部位のレベル** で決まる
  - 同じ種目のカードは、全部まとめて重量が上がる
  - 重量は「強化までの進み具合」を表すだけ。目標重量に届いたら **カードが強化される**（スレスパの「+」）
  - 1レベルで何kg上がるか、何レベルで強化されるかはカードごとに違う

| 種目 | スタート | 目標 | 1レベルで | 強化に必要なレベル |
|---|---|---|---|---|
| ベンチプレス | 60kg | 100kg | +10kg | 4 |
| スクワット | 80kg | 140kg | +15kg | 4 |
| ラットプルダウン | 40kg | 60kg | +5kg | 4 |
| アームカール | 10kg | 16kg | +2kg | 3 |
| サイドレイズ | 6kg | 10kg | +2kg | 2 |

- 強化は **基本1回だけ**。ただし **一部の特別な種目だけ何段階も強化できる**（+、++、+++ …）

- 何段階も強化できるのは **BIG3**（ベンチプレス・スクワット・デッドリフト）
  - 例：ベンチプレス 100kg → 120kg → 140kg
- BIG3以外は、強化後も **重量の数字だけ上がり続ける**（効果なし。自己ベスト記録として楽しむ）

- 部位レベルは、重量以外に次のことに使う
  - **見た目**：キャラの筋肉が部位ごとに大きくなる
  - **実績**：「ベンチ100kg達成」などのやり込み要素
  - **一部のレリックの効果**：部位レベルや重量を参照するレリック
